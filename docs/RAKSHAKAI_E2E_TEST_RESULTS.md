### Browser failures and harness corrections

1. An initial full browser run failed at GIS route clearing because the UI kept Clear Route enabled with no calculated route. 3. The first generated WebM was only 500 ms. Chromium intermittently rejected it as incomplete (`DEMUXER_ERROR_COULD_NOT_OPEN`). The test fixture now records 30 frames; the evidence decoding assertion was retained.

6. Backend restarts between scenarios emitted a Node `MaxListenersExceededWarning` from piping each process to one shared test log stream. All 15 scenarios completed; this is a test harness warning, not an application page exception or observed API failure.
